# 🎮 The Perfect Arcade

A mini arcade of classic games, built as part of Hack Club's Comeback. the theme is taken from stasis website.

**[▶ Play it live](https://rajeev-likes-biryani.github.io/Hackclub-comeback/)**

## Games

| Game | Description |
|------|-------------|
| 🪙 **Heads or Tails** | Guess the same as the computer. |
| ✊ **Rock Paper Scissors** | Rock beats scissors, scissors beat paper, paper beats rock. Win against the bot. My practice build. |
| ❌⭕ **Tic Tac Toe** | 3 in a row wins. Two players (or play against yourself). Built after following a tutorial. |

## About this project
The Rock Paper Scissors game was a solo practice project, and Tic Tac Toe came out of a tutorial that I then rebuilt and tweaked myself. Everything is combined into one arcade page with interactive ASCII art. The index.js, index.css and index.html contain the main files.
